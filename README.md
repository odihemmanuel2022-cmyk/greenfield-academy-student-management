Greenfield Academy Student Management System

Project Overview

The Greenfield Academy Student Management System is a student-tracking solution built with Notion to help schools organize student records and monitor academic performance and school-fee payments.

The Problem

Managing student information manually can make it difficult to track examination scores, organize classes, and identify outstanding school-fee payments.

The Solution

This system provides a centralized dashboard for organizing student records and making important information easier to access.

Key Features

* Student Records: Store and organize student information.
* Class Management: Group students by class.
* Academic Tracking: Record examination scores and sort students by performance.
* Payment Tracking: Identify students whose school fees have been paid or remain outstanding.
* Filtered Views: Separate paid and unpaid students for easier monitoring.
* Quick Student Entry: Use a template and button to simplify the process of adding student records.

Tools Used

* Notion — database, dashboard, and student management.
* Notion formulas and database views — for payment status and organized reporting.

Project Purpose

This project demonstrates practical skills in workspace design, database organization, dashboard development, and business process improvement.

Future Improvements

* Automated parent notifications.
* Academic performance reports.
* More advanced school administration workflows.
